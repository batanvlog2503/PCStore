5. Có 3 khái niệm cần nhớ

startTransaction

bắt đầu 1 transaction -> BEGIN

commitTransaction

Xác nhận tất cả các thay đổi -> COMMIT 
sau commit thì thay đổi được lưu chính thức

abortTransaction

hủy Transaction -> ROLLBACK toàn bọ thay đổi trong transaction bị quay lại


6. MongoDB /Mongoose làm như nào? 

Vì Project bạn dùng mongoose

tại sao phải cần session 
-> để biết nhưng thao tác database nào thuộc về transaction

session.startTransaction()

hoặc nếu lỗi:

7. Cấu trúc cơ bản

Đừng vội đưa vào Order. Trước tiên hãy nhớ cấu trúc này:

const session = await mongoose.startSession()



try {
  session.startTransaction()

  // database operation 1
  // database operation 2
  // database operation 3

  await session.commitTransaction()
} catch (error) {
  await session.abortTransaction()

  throw error
} finally {
  session.endSession()
}

Đọc theo tiếng Việt:

Tạo session
   ↓
Bắt đầu transaction
   ↓
Làm các thao tác DB
   ↓
Nếu tất cả OK
   ↓
COMMIT

Nếu có lỗi
   ↓
CATCH
   ↓
ROLLBACK

Cuối cùng
   ↓
Đóng session\
